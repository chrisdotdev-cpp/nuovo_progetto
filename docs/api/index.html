Gestionale Sanitario — API v1

Documentazione interattiva generata dalla specifica OpenAPI 3.0.3

Come provare le chiamate. Avvia il backend con php artisan serve, poi esegui POST /auth/login con una delle utenze demo (paziente@clinica.it, medico@clinica.it, admin@clinica.it — password password). Copia il token dalla risposta, premi Authorize qui sopra e incollalo: da quel momento ogni richiesta viene inviata autenticata. Ricorda che i permessi dipendono dal ruolo dell'utenza scelta.
Specifica non caricata. Il file openapi.yaml viene richiesto via fetch, che i browser bloccano quando la pagina è aperta con doppio clic (protocollo file://). Avvia un server locale dalla cartella docs/api/ — per esempio python -m http.server 8080 — e apri http://localhost:8080. In alternativa pubblica la cartella con GitHub Pages.
